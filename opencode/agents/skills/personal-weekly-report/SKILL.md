# 个人周报生成技能

## 任务

根据用户提供的工作内容和时间范围，生成可直接复制填写的个人周报文本。不生成 Excel 文件，由用户手动填写到周报表格。

## 输入

用户需要提供：
1. **时间范围**：格式为 `YYYYMMDD~YYYYMMDD`，例如 `20260420~20260424`
2. **工作内容**：一周的工作记录文本

## 处理步骤

### 1. 总结工作内容

对工作内容进行总结，先按项目分组，每个项目下再分为**功能开发**和**日常运维**两类：
- **功能开发**：涉及代码编码的工作，如功能修复、功能改造、脚本调整、漏洞修复、接口开发等。
- **日常运维**：部署、授权、映射、配置、问题排查处理等非编码工作。

每个项目用一句话总结，合并相似内容，突出核心成果和解决的问题。

### 2. 解析时间范围

将时间范围 `YYYYMMDD~YYYYMMDD` 转换为标题：
- **标题格式**：`个人周报（YYYY.M.D-YYYY.M.D）`
- 月份和日期去掉前导零（如 `04` 显示为 `4`）

### 3. 直接输出文本

在对话中直接输出周报文本，不保存文件。格式如下：

```
个人周报（YYYY.M.D-YYYY.M.D）

项目名称
- 功能开发：<一句话总结>
- 日常运维：<一句话总结>

项目名称
- 功能开发：<一句话总结>
```

## 输出示例

**输入**：
```
20260921~20260924
群租房公安网无法登录的问题处理。
行业场所部级旅客数据上报及时率汇报功能修复。
行业场所等保检测安全报告漏洞修复：垂直越权。
公共工具测试环境网约房自动部署脚本增加分支、停止服务选项。
山东短租房互联网数据库授权更新。
行业场所服务端、前端部署更新。
全国旅馆重庆旅馆前端部署更新。
```

**输出**：
```
个人周报（2026.9.21-2026.9.24）

群租房
- 日常运维：完成公安网无法登录问题处理。

行业场所
- 功能开发：完成部级旅客数据上报及时率汇报功能修复、等保检测安全报告垂直越权漏洞修复、旅客与操作日志同步搜索引擎错误及时间误差修复、预警信息时间转换错误修复、不能指派临时勤务问题修复，实现前端门户安卓应用下载与娱乐特行小程序恢复正常显示。
- 日常运维：完成服务端、前端部署更新。

公共工具
- 功能开发：完成测试环境网约房自动部署脚本新增分支选择、停止服务选项。

山东短租房
- 日常运维：完成互联网数据库授权更新、互联网东方通中间件授权更换、雷达管理系统公网访问映射配置。

全国旅馆
- 日常运维：完成重庆旅馆前端部署更新。
```

## 注意事项

- 直接在对话中输出文本，供用户手动复制填写，不生成 Excel 文件
- 时间范围解析时，月份和日期去掉前导零（如 04 显示为 4）
- 每个项目独立成组，组内按「功能开发 / 日常运维」分类；某项目只有一个分类时只输出该分类
- 总结内容要简洁，每个项目一句话
- 涉及代码编码的内容一律归入功能开发
